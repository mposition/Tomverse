# Wordmark font

`roboto-latin-variable.woff2` is the unmodified Latin subset of Roboto Classic,
with variable weights 100–900. Tomverse uses weight 650 only for its wordmark.
Both web and the locally bundled mobile app import `../wordmark.css`; neither
needs a runtime Google Fonts request. Body typography is independent.
