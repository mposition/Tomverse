## What round 6 found, and what I changed

1. **blocker — the deadline window allowed a cron period (5 min) for a run
   deadline of 4 min.** With the route measuring against the database clock, a
   service 30s ahead submitted `db_now + 4m30s`, was accepted, and a close at
   4m15s was not late by the trigger's clock. The bound is `runDeadlineMs` now.
   Tested at 1s, 30s and 59s of skew, plus an agreeing-clock case so the
   request's own latency does not refuse every run. **Check the boundary
   arithmetic**: is `>` right rather than `>=`, and can a legitimate run with a
   slow request now be refused?
2. **major — the run's own database work had no ceiling.** The clock read, start,
   heartbeat and close ran on the bare client with `statement_timeout` at whatever
   the connection carried. They go through a new `withStatementBound` helper,
   which opens a transaction and arms only `statement_timeout`. I deliberately did
   *not* use `runBoundedMarketingTransaction` (PG17 demand, SERIALIZABLE, three
   GUCs, statement counting) for single-row writes. **Check whether that
   reasoning holds**: does wrapping `create` in a transaction change how the
   duplicate-key and trigger SQLSTATEs surface? Does the Prisma interactive
   transaction timeout interact badly with the statement ceiling? Is arming
   `statement_timeout` without `transaction_timeout` on PostgreSQL 17 actually
   effective, given 17 arms the statement ceiling only while it is shorter than
   an active transaction timeout — and there is none here?
3. **major — the alias lint watched the original name, not the local one.**
   `import { X as bounded }` then `const run = bounded` produced no call site. It
   tracks local bindings now and refuses a renamed re-export. **Try to defeat it
   again**: a three-step alias, a default import, a namespace whose property is
   assigned to a local, a call through an object literal.
4. **major — the clock-failure path reported no incident.** It does now.
5. **minor — `introducedBy` omitted a function expression's own name**, refusing a
   safe recursive callback. Fixed; a named class expression too.

## The rest of the slice
