# Admin 사용 현황 탭 staging 검증 체크리스트

`/admin/analytics?tab=usage`(PR #1539, 수정 #1541)의 staging 검증입니다.

- **template revision**: `2026-09-17a`

## 이 문서는 template입니다

**여기에는 결과가 없습니다.** 실행 결과는 날짜와 전체 deploy SHA로 이름 붙인
별도 파일로 `admin-usage-analytics-staging-verification-records/`에 남깁니다.

실행·판정·서명은 사람이 합니다. 에이전트는 실행자가 **보고한 관측**을 기록
초안에 옮겨 적을 수 있고, **판정과 서명**은 쓰지 않습니다.

## 무엇이 차단이고 무엇이 아닌가

기준은 AGENTS.md의 **틀렸을 때 되돌릴 수 없는가**입니다.

- **차단 — A 하나.** 이 탭은 전체 사용자에 대한 집계를 보여 줍니다. 권한 없는
  사람에게 한 번 노출된 집계는 회수되지 않습니다.
- **비차단 — B·C·D.** 이 기능은 읽기 전용이라(`SET TRANSACTION READ ONLY`) 어떤
  항목도 데이터를 바꾸지 않습니다. 숫자·화면·문구의 결함은 고쳐서 배포하면
  끝납니다.

**운영 부하**는 staging 데이터량으로 판단할 수 없어 넣지 않았습니다.

## A. 권한 — 차단, 무료

- [ ] **B1** 관리자가 아닌 로그인 계정과 비로그인 창에서 각각
      `/admin/analytics?tab=usage`를 열면 통계 없이 로그인 또는 거부 화면이 나옴.

## B. 화면 동작 — 비차단, 무료

- [ ] **O1** Analytics를 열면 첫 탭이 사용 현황이고 기간 "오늘"이 선택되어 있음.
- [ ] **O2** 기간 6개를 누르면 주소가 `period=…`로 바뀌고, 선택 표시가 따라가고,
      기간 문구와 비교 기간이 브리즈번 날짜로 나옴.
- [ ] **O3** 최근 30일·이번 달이 뜨기까지 걸린 초를 적음. 조회 실패 안내가 뜨면 그
      사실을 적음.
- [ ] **O4** 제품 분석 탭이 기존과 같이 보임.

## C. 집계 — 비차단, 유료 turn 2회

- [ ] **O5** 로그인 테스트 계정으로 메시지를 보낸 뒤 "오늘"을 새로고침하면 활성
      계정·보낸 메시지·모델 요청이 늘고 모델 점유율 표에 그 모델이 보임. 모델 N개에
      보내면 모델 요청은 +N.
- [ ] **O6** 게스트로 메시지 1개를 보낸 뒤 새로고침하면 활성 게스트와 모델 요청이
      늘고 보낸 메시지는 그대로임.
- [ ] **O7** 히트맵에서 방금 보낸 요청이 브리즈번 기준 현재 요일·시간 칸에 찍힘.

## D. 표시 품질 — 비차단, 무료

- [ ] **O8** 한국어 콘솔에서 탭 문구가 한국어이고 모델 ID·공급자는 원래 표기임.
- [ ] **O9** 휴대폰 폭에서 페이지 전체가 가로로 밀리지 않음. 히트맵과 모델 표는
      자기 영역 안에서만 가로 스크롤됨.
