# Chat 시작 카탈로그 staging 검증 체크리스트

`docs/ui-contracts/chat-starter-catalog.md`가 요구하는 검증입니다. 이 체크리스트의
실행과 서명은 production에서 `feature.chatStarterEnabled`를 켜기 위한 전제
조건입니다.

- **template revision**: `2026-09-15a`

## 이 문서는 template입니다

**여기에는 결과가 없습니다.** 체크박스는 항상 비어 있고, 그것이 이 파일의
상태입니다. 실행 결과는 날짜와 전체 deploy SHA로 이름 붙인 별도 파일로
`chat-starter-catalog-staging-verification-records/`에 남깁니다.

실행·판정·서명은 사람이 합니다. 에이전트는 항목을 갱신하고 실행자가 **보고한
관측**을 기록 초안에 옮겨 적을 수 있습니다. 쓸 수 없는 것은 **판정과 서명**뿐이며,
**지어낸 관측은 어느 쪽에서도 허용되지 않습니다.**

---

## 비용: 유료 turn 0회

**차단 항목 3개가 전부 무료입니다.** 이 표면은 provider를 부르지 않고, 크레딧을
예약하지 않으며, 행을 쓰지 않습니다. 카드 클릭은 composer 초안을 채우고 멈춥니다.

유료가 되는 지점은 단 하나 — 씨앗이 채워진 뒤 **사람이 전송 버튼을 누르는
것**이고, 그것은 이 기능의 검증이 아니라 기존 chat의 검증입니다. 아래 어느
항목도 그것을 요구하지 않습니다.

## 항목 수

| 구획 | 항목 | 차단 | 비용 |
|---|---|---|---|
| A. flag off | 2 | 예 | 무료 |
| B. 약속의 진실성 | 3 | 예 | 무료 |
| C. 씨앗은 전송이 아니다 | 4 | 예 | 무료 |
| D. 잠금 노출 | 3 | 아니오 | 무료 |
| E. 실기기 기하 | 4 | 아니오 | 무료 |
| F. 문구·운영 | 3 | 아니오 | 무료 |

**차단 9항목 / 전체 19항목 / 유료 turn 0회.**

범위를 줄이면 A·B·C만 실행합니다. 건너뛴 구획은 `미기록`이며, 판정란에 **무엇을
왜 건너뛰었는지** 적습니다.

## 무엇이 차단이고 무엇이 아닌가

기준은 AGENTS.md의 **틀렸을 때 되돌릴 수 없는가**입니다.

**차단 — 세 가지뿐이고, 한 줄로 적을 수 있습니다.**

- **B (약속의 진실성)**: 없는 기능을 약속한 카드를 보고 한 가입·결제는 고쳐서
  배포한다고 회수되지 않습니다. `docs/ui-contracts/chat-starter-catalog.md` §9가
  이 표면의 유일한 release blocker로 지목한 것입니다.
- **C (초안 파괴)**: 전송되지 않은 초안에는 이력 테이블이 없습니다. 카드
  클릭이 사람이 타이핑한 문장을 지우면 그 문장은 사라집니다.
- **A (kill switch)**: B가 production에서 일어났을 때의 회수 경로입니다. 회수
  경로가 동작하지 않으면 되돌릴 수 있는 사고가 되돌릴 수 없는 사고가 됩니다.

**비차단** — D(잠금 노출), E(기하), F(문구). 전부 고쳐서 배포하면 끝나는
것입니다. "중요해 보인다"는 차단 근거가 아닙니다.

## 왜 항목이 이것뿐인가

AGENTS.md의 "사람에게 남기는 것은 사람만 할 수 있는 것뿐입니다"에 따라, 이
컨테이너에서 만들 수 있는 것은 전부 만들어 두었습니다.

이미 자동화되어 **여기서 다시 하지 않는 것**:

| 이미 증명된 것 | 어디서 |
|---|---|
| available / locked / hidden 판정 행렬과 fail-closed 경로 | `tests/chatStarterCatalog.test.mjs` |
| 화면 상한, 예약된 잠금 자리, 상한 1의 경계 | 같은 파일 |
| flag 기본값 off와 kill switch 우선순위 | 같은 파일 |
| flag off일 때 아무것도 렌더하지 않음 (desktop·mobile) | `tests/e2e/chat-starter-catalog.spec.ts` |
| 잠긴 카드가 클릭 전에 요구사항을 말함 | 같은 파일 |
| 클릭이 초안만 채우고 전송하지 않음 | 같은 파일 |
| 타이핑한 초안을 덮어쓰지 않음 | 같은 파일 |
| 320px·200% 배율에서 composer 행 미침범, 가로 overflow 0, 44px 타깃 | 같은 파일 |
| image flag off일 때 image 카드 부재(잠김 아님) | 같은 파일 |
| flag 상수·capability 해석기·evidence 경로·7개 locale 전수 | `npm run check:starter-catalog` |
| 우월성 주장·em/en dash 부재 | 같은 검사 |
| 역할 token만 사용, AI Review gradient 미사용 | `npm run check:accent-tokens` |

**정답지도 만들어 두었습니다.** 어느 카드가 보여야 하는지를 화면 앞에서
추론하지 않습니다:

```
npm run report:starter-catalog-expectations -- --image=<on|off> --voice=<on|off> --brave=<on|off>
```

앱과 같은 순수 함수를 부르므로 이 표와 화면이 어긋나면 둘 중 하나가 결함이고,
그것이 이 검증이 찾는 것입니다.

**남는 것은 넷 중 둘뿐입니다** — 실기기·실제 OS, 그리고 판정·서명.

하나라도 어긋나면 검증이 아니라 **다른 것을 측정**하게 됩니다.

- [ ] staging이 서빙 중인 **전체 40자리 SHA**를 `GET /api/build-info`에서 읽음
      (로그인 불필요). merge SHA를 옮겨 적지 않습니다 — staging은 develop에
      무엇이 병합되든 재배포됩니다.
- [ ] 그 SHA가 `4f300e21`(PR #1433 merge) 이후임
- [ ] Admin → 플랫폼 설정에서 **이미지 생성**과 **음성 입력** flag의 현재
      값을 읽어 적음. 이 둘이 정답지의 입력입니다.
- [ ] 위 값으로 `report:starter-catalog-expectations`를 실행해 정답지를 손에 쥠
- [ ] 로그인 계정 1개(플랜을 적음) + 비로그인 세션 1개
- [ ] 실기기 1대 이상(E 구획을 할 경우)

## A. flag off는 비활성이 아니라 부재다 — 차단, 무료

`feature.chatStarterEnabled`가 꺼진 상태에서 시작합니다.

- [ ] **A-1** 새 대화 환영 화면에 갤러리가 **전혀 없음**. 제목도, 빈 틀도, 자리를
      차지하는 빈 행도 없음. 비활성화된 카드도 없음.
- [ ] **A-2** Admin에서 켠 뒤 새로고침하면 갤러리가 나타나고, 다시 끄면 다시
      완전히 사라짐.

`CHAT_STARTER_KILL_SWITCH`는 배포 환경변수이므로 이 회차에서 켜 볼 수 없다면
`미기록`으로 두고 판정란에 적습니다. A-2가 그 대체 증거는 아닙니다 — 저장된
flag와 kill switch는 서로 다른 스위치입니다.

## B. 카드는 이 배포가 실제로 하는 일만 약속한다 — 차단, 무료

정답지를 옆에 두고 봅니다.

- [ ] **B-1** 화면의 카드 집합이 정답지의 "on screen" 목록과 **정확히** 일치
      (개수·순서·id).
- [ ] **B-2** 정답지의 "Must NOT appear"에 있는 카드가 화면에 **하나도 없음**.
- [ ] **B-3** 특히: 이미지 생성 flag가 꺼져 있다면 `compare-image-models` 카드가
      **부재**(잠김 아님). 음성 입력 flag가 꺼져 있다면 `speak-a-question`이
      **부재**.

어긋나는 것이 하나라도 있으면 **그 자리에서 추론해 화해시키지 않습니다.** 무엇이
보였고 무엇이 없었는지를 그대로 적는 것이 관측입니다.

## C. 씨앗은 전송이 아니다 — 차단, 무료

- [ ] **C-1** 빈 composer에서 카드를 클릭 → 입력란이 그 카드의 문장으로 채워짐.
      **전송되지 않음**(답변 영역에 아무것도 생기지 않음, 크레딧 변화 없음).
- [ ] **C-2** 이어서 다른 카드를 클릭 → 문장이 **교체**됨.
- [ ] **C-3** 입력란에 아무 문장이나 직접 타이핑한 뒤 카드를 클릭 →
      **타이핑한 문장이 그대로 남아 있음**. 카드 문장으로 바뀌지 않음.
- [ ] **C-4** 출처 카드(`sourced-answer`)를 클릭하면 composer의 웹 검색이 켜진
      상태가 됨. 이 역시 전송은 아님.

**C-3이 이 구획의 이유입니다.** 나머지 셋이 통과해도 C-3이 실패하면 차단입니다.

## D. 잠금은 클릭 전에 말한다 — 비차단, 무료

- [ ] **D-1** 비로그인 상태에서 잠긴 카드가 **보이고**, 요구사항이 카드 위에
      적혀 있음(클릭 후가 아님).
- [ ] **D-2** 그 카드를 클릭하면 로그인으로 감. 초안은 채워지지 않음.
- [ ] **D-3** (이미지 flag가 켜져 있고 Free 계정일 때) `compare-image-models`가
      **잠김으로 보이고** 요금제를 말하며, 클릭하면 `/pricing`으로 감.

## E. 실기기 기하 — 비차단, 무료

E2E가 합성 브라우저에서 이미 고정한 것이므로, 여기서 보는 것은 **실제 OS와 실제
글꼴**입니다.

- [ ] **E-1** 세로 모드에서 갤러리가 입력란의 가로 행을 침범하거나 겹치지 않음.
- [ ] **E-2** 가로 스크롤이 생기지 않음.
- [ ] **E-3** OS 글자 크기를 최대로 올려도 카드 문장이 잘리지 않고 줄바꿈함.
- [ ] **E-4** 한국어 IME로 입력 중에 카드를 클릭해도 조합 중인 글자가 깨지거나
      사라지지 않음.

## F. 문구와 운영 — 비차단, 무료

- [ ] **F-1** 언어를 바꿔 가며 카드 문장이 그 언어로 나옴(영어 문장이 남아 있지
      않음). 최소 ko / en, 가능하면 하나 더.
- [ ] **F-2** 카드 어디에도 **가격이 표시되지 않음**. 유료 요구는 잠금 사유로만.
- [ ] **F-3** Admin에서 이 flag를 켜고 끈 것이 `AdminAuditLog`에
      `app_settings.update_completed`로 남음.
