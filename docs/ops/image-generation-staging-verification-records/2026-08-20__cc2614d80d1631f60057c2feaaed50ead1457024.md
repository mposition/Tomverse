# 이미지 생성 production 기준선 — 2026-08-20 / `cc2614d`

`#681`(develop → main) 배포 직후, **아무것도 생성하지 않고** production의
`GET /api/admin/image-generation`을 읽은 기록입니다. 활성화 전 기준선이며 검증
실행이 아닙니다.

```
production  cc2614d80d1631f60057c2feaaed50ead1457024
            deployment f10363dc-9393-4d44-8cfe-134dfb3419e0
            deployedAt 2026-08-20T00:39:08Z   (/api/build-info)
flag        feature.imageGenerationEnabled = false
```

## 이 판독이 가능해진 이유

`ae649be`까지의 production은 provider별 *한도* 옆에 **openai의 사용량만**
보여 줬습니다. 아래 표의 xai·fal 열은 이 배포 전에는 읽을 방법이 없었습니다.

## 배분이 어긋나 있고, 총액은 맞다

| provider | 정산 합계 | 월 버킷 | 차이 |
|---|---|---|---|
| openai | 106,105 | 94,105 | **−12,000** |
| xai | 50,000 | 55,000 | **+5,000** |
| fal | 80,000 | 87,000 | **+7,000** |
| 합계 | 236,105 | 236,105 | 0 |

**12,000 = 5,000 + 7,000**입니다. xai와 fal의 true-up이 자기 버킷이 아니라
openai 버킷에서 빠졌다는 뜻이고, 2026-08-16에 진단한 결함의 정확한 서명입니다.
그때는 openai 버킷 한쪽만 보고 "약 12,000이 모자란다"고 적었는데, 이제 세
버킷을 다 읽어 **그 12,000이 어디로 갔는지**까지 확인됐습니다.

총액이 맞는 것이 핵심입니다 — 돈이 새거나 이중으로 잡힌 것이 아니라 **어느
provider에 달았는지**만 틀렸습니다. 4건 모두 수정 배포 이전 생성이고, 수정은
지금 production에 있으므로 새 생성부터는 자기 버킷으로 갑니다.

## orphaned 예약 없음

예약 4건이 전부 정산됐고(`reservedCredits` 335 = `settledCredits` 335), 예약
총액이 provider별 최악 원가로 정확히 떨어집니다.

```
openai 2 x 58,000 + xai 55,000 + fal 87,000 = 258,000 = reservedCostMicroUsd
```

staging에서 116,000을 붙들고 있던 모양(generation 없는 예약)은 production에
없습니다. 다만 이 배포에는 `orphanedReservations` count가 **아직 없습니다**
(`#683`은 develop에만 있음). 위는 보고된 합계에서의 산술이며, count가 배포되면
0으로 확인되어야 합니다.

## 추가 — Guest·Free 잠금 (staging 확인) 과 두 트리의 동일성

`@mposition`이 staging에서 Guest와 Free 계정 모두 이미지 생성이 잠겨 있음을
확인했습니다. 증거로 남은 화면은 사이드바 split button의 드롭다운이며,
`새 이미지` 행이 **보이는 상태로** 자물쇠와 `로그인` 배지를 달고 있습니다 —
계약이 요구하는 "숨기지 않고, 마지막 단계에서 막지 않고, 요구 조건을 클릭 전에
말한다"에 해당합니다.

이 확인이 production으로 넘어오는 근거는 두 트리가 같다는 사실입니다.

```
git diff --stat 6fb0a9e cc2614d
  docs/ops/.../2026-08-19__6fb0a9e….md      (검증 기록)
```

것과 같은 코드를 서빙하며, 차이는 문서 한 건과 테스트 한 건뿐입니다.

남은 미확인 항목은 두 가지입니다.

- **부분 실패 경로** — 코드 근거로 종결했습니다. 처음 실행되는 곳은
  production입니다.

  컴포저의 `n/max` 카운터로 바로 읽힙니다.
