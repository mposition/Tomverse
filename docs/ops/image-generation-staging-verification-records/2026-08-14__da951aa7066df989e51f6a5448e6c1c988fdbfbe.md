### 발견 사항

1. **Nano Banana 2 행의 공급자 이름 누락 (`fail`)** — 카탈로그 이미지 탭에서 해당 행이 `· 보통`으로 렌더돼 브랜드명이 비어 있었다. 원인은 두 가지가 겹친 것: 라벨 표가 `Record<string, string>`이라 `fal` 항목 누락이 타입 검사를 통과했고, 행이 `provider`를 표시하고 있어 소유자와 공급자가 갈리는 첫 모델에서 드러났다. 정책 §16.1은 소유자 브랜드를 보이고 gateway를 명시하도록 요구한다. PR #567로 수정.
2. **카탈로그 크레딧이 하한임이 화면에 드러나지 않음 (개선 필요, `fail` 아님)** — 탭은 `Math.min(...prices)`로 "N크레딧부터"를 의도하나, 화면에는 배지 숫자만 보이고 "부터"가 접근성 라벨에만 있다. GPT Image 2가 탭에서 15, 컴포저에서 70으로 보여 서로 다른 가격으로 읽힌다. 숫자 규칙 자체는 계약대로다.
3. **fal 정산 원가가 실제 청구보다 2,000µUSD 적게 기록됨 (관측)** — `settledCostMicroUsd: 80000`이나 실제 청구는 `1.025 units × 80,000 = 82,000µUSD`(high thinking 할증). 사용자 과금은 고정 120크레딧이라 영향 없으나, provider 예산 집계가 실지출을 약 2.5% 적게 센다.
4. **openai·xai 예산의 월 한도가 일 한도와 동일 (기존 설정, 이번 작업 무관)** — admin 응답이 `month_not_above_day` advisory를 스스로 보고한다. 하루만 한도까지 쓰면 그 달이 소진된다. fal은 12M/50M으로 정상.
