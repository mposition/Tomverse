## 정리 의무

이 회차는 staging 계정에 profile·knowledge 행을 남기고, **R2 object도
남깁니다.** 취소한 import가 지웠어야 할 것이 실제로 사라졌는지도 여기에
적힙니다 — 그것이 §E-3·E-4의 사후 증거입니다.

**서명 시점에 이 표는 비어 있습니다.** 정리는 아직 수행되지 않았고, 나중에
채우면 그것은 관측이 아니라 사후 기입입니다(기록 README 2번). 남은 작업은
**별도 후속**으로 다루며, 이 회차의 판정은 정리 완료를 전제하지 않습니다 —
staging의 행과 객체는 되돌릴 수 있는 것이고 만료 sweep이 가져갑니다.
