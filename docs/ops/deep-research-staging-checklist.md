# 딥 리서치 확장 staging 검증 체크리스트

답변이 끝난 뒤 제시되는 **딥 리서치 확장 제안**과, 모델 상한에서 그것을 누를 때
뜨는 **교체 다이얼로그**를 staging에서 확인하는 항목입니다.

대상 변경은 PR #1072 · #1074 · #1092 이며, 계약 문서는
`docs/ui-contracts/comparison-action-rail.md`(제안 카드가 차용한 원칙)와
`AGENTS.md`의 "검증 범위는 되돌릴 수 없는 것에 비례합니다"입니다.

실행·판정·서명은 사람이 합니다. 에이전트는 항목을 갱신하고 실행자가 보고한
관측을 기록 초안에 옮겨 적을 수 있습니다. 쓸 수 없는 것은 **판정과 서명**뿐이며,
지어낸 관측은 어느 쪽에서도 허용되지 않습니다 — 기록 README의 5번 참조.

## 이 문서는 template입니다

**여기에는 결과가 없습니다.** 체크박스는 항상 비어 있고, 그것이 이 파일의
상태입니다. 실행 결과는 `deep-research-staging-verification-records/`에 **날짜와
전체 deploy SHA로 이름 붙인 별도 파일**로 남습니다.

- **template revision**: `2026-08-27b` — 항목이 바뀌면 이 값을 올리고, 실행
  기록은 자기가 어느 revision으로 실행됐는지 적습니다.
- 실행 방법과 파일 이름 규칙:
  `deep-research-staging-verification-records/README.md`
- 기록 template:
  `deep-research-staging-verification-records/_record-template.md`

## 릴리스 차단 항목은 하나입니다

`AGENTS.md`의 기준 — **무엇이 복구 불가인지 한 줄로 적을 수 없으면 차단이
아니다** — 로 이 변경을 하나씩 확인한 결과입니다.

| 후보 | 판정 |
|---|---|
| **B-2** 고른 모델이 실제로 빠지는가 | **차단.** 아래 한 줄 참조 |
| 제안 카드가 안 뜸 / 잘못 뜸 | 차단 아님. 고쳐서 배포하면 끝난다 |
| 카드 문구·간격·다크모드 | 차단 아님 |
| 시간·크레딧 표기 오류 | 차단 아님. 잘못된 과금은 환급된다 |
| 취소가 실행을 안 멈춤 | 차단 아님. 크레딧은 환급되고 답변은 남는다 |

**차단 사유 한 줄**: 사용자가 고른 것과 다른 모델이 빠지면, 그 모델의 패널과
거기 담긴 답변이 대화에서 사라지고 `Conversation.selectedModels`에는 이력
테이블이 없어 무엇이 있었는지 복원할 수 없습니다.

이 변경이 **없애는** 것도 같은 종류입니다 — 이전에는 상한에서 마지막 모델을
확인 없이 버렸습니다. 그래서 이 검증의 핵심은 "묻는가"가 아니라 **"물어 놓고
답한 대로 하는가"** 입니다.

schema 변경, pin된 version 쓰기, 소유권 판정 변경은 **하나도 없습니다.**

## 필수는 3항목, 유료 2 turn

**이것만 하면 이 회차는 성립합니다.**

| 항목 | 무엇을 판별하는가 | 비용 |
|---|---|---|
| **B-2** | 고른 모델이 빠지고, **고르지 않은 둘은 답변과 함께 남는가** | 유료 1 turn (딥 리서치, 아래 표 참조) |
| **B-3** | 취소하면 실행도 없고 선택도 그대로인가 | 무료 |
| **A-2** | 상한 상태를 만들고 제안 카드까지 도달 | 유료 1 turn (일반 모델 3개) |

`A-1`(배포 SHA 기록)은 항목이 아니라 기록의 전제입니다. `A-2`는 B를 하려면
지나야 하는 단계라 따로 세지 않아도 되지만, 일반 답변 1 turn을 쓰므로 비용
표에는 남깁니다.

나머지 C·D·E·F는 **선택**입니다. 하면 좋지만, 안 해도 이 회차는 유효하고
건너뛴 것은 기록의 `미기록`입니다.

### 딥 리서치 1 turn의 크레딧은 고정값이 아닙니다

기본 **30크레딧**(`MODEL_USAGE_CREDIT_WEIGHTS.deepResearch`)에 입력 길이 배수가
곱해집니다. `lib/models.ts`의 `INPUT_CREDIT_MULTIPLIERS`입니다.

| 예상 입력 토큰 | 배수 | 크레딧 |
|---|---|---|
| 16,000 이하 | ×1 | 30 |
| 16,000 초과 | ×1.5 | 45 |
| 50,000 초과 | ×2 | 60 |
| 100,000 초과 | ×3 | 90 |

**모델 행의 `creditWeight: 16`은 이 클래스에서 쓰이지 않습니다.**
`usageClass: "deep-research"`는 위 표의 30을 씁니다. 행의 숫자를 그대로 읽으면
틀립니다.

카드가 누르기 전에 표시하는 숫자가 그 회차의 예상치이므로, **기록에는 카드에
뜬 숫자와 실제 정산 크레딧을 함께** 적습니다. 둘이 다른 것은 결함이 아니라
정산 결과이지만, 차이가 크면 그 자체가 관측입니다.

## 질문은 준비돼 있습니다

이 기능의 판별은 **어떤 질문을 하느냐**에 달려 있습니다. 제안은 최신 자료
비교가 실제로 도움이 되는 질문에만 뜨고, 번역·요약·단순 사실 확인에는 뜨지
않습니다. 실행자가 질문을 즉석에서 지어내면 "안 떴다"가 결함인지 정상인지
구분되지 않으므로, 아래 문장을 **그대로** 씁니다.

| 용도 | 질문 (그대로 복사) | 기대 |
|---|---|---|
| 제안이 떠야 함 | `2026년 전고체 배터리 시장의 최신 자료를 비교해서 정리해줘` | 카드 표시 |
| 제안이 떠야 함 (영문) | `Compare the latest sources on the 2026 solid-state battery market` | 카드 표시 |
| 뜨면 안 됨 (번역) | `다음 문장을 영어로 번역해줘: 회의가 취소되었습니다` | 카드 없음 |
| 뜨면 안 됨 (단순 사실) | `오늘 서울 날씨 알려줘` | 카드 없음 |
| 뜨면 안 됨 (코드) | `파이썬으로 리스트를 뒤집는 코드 써줘` | 카드 없음 |

판정 근거는 `lib/deepResearchSuggestion.ts`의 `classifyDeepResearchTopic`이며,
최신성 신호 하나만으로는 제안하지 않습니다 — 그래야 "오늘 서울 날씨"가 이
카드의 가장 흔한 등장이 되지 않습니다.

## A. 사전 조건

- [ ] **A-1** 배포 SHA를 기록에 적는다 (전체 40자리). production과 같은지도
      적는다. `GET /api/build-info`
- [ ] **A-2** Pro 계정으로 로그인하고 **모델 3개를 선택**한다(상한). 위 표의
      "제안이 떠야 함" 질문을 보내 세 답변을 받는다 — 유료 1 turn
- [ ] **A-3** 답변이 **모두 끝난 뒤에만** 제안 카드가 나타나는 것을 확인한다.
      스트리밍 중에는 없어야 한다

## B. 상한에서의 교체 — 차단 구획

- [ ] **B-1** `딥 리서치로 확장`을 누른다. **교체 다이얼로그가 뜬다.** 세 모델이
      모두 선택지로 보인다
- [ ] **B-2** 그중 **하나를 고른다.** 딥 리서치가 시작되고, **고른 모델의 패널만
      사라지며 나머지 둘은 이전 답변을 그대로 유지**한다 — 유료 1 turn
- [ ] **B-3** (별도 대화에서) 같은 지점까지 간 뒤 다이얼로그를 **Esc로 닫는다.**
      실행이 시작되지 않고, 세 모델이 그대로 남는다 — 무료

B-2의 관측은 "무엇이 사라졌는가"가 아니라 **"고른 것이 사라졌는가"** 입니다.
기록에는 고른 모델 이름과 남은 모델 이름을 함께 적습니다.

## C. 상한 미만 경로 (선택)

- [ ] **C-1** 모델 **2개**만 선택한 대화에서 같은 질문을 보내고 확장을 누른다.
      **다이얼로그 없이** 바로 시작한다 — 유료 1 turn
- [ ] **C-2** 딥 리서치가 세 번째 패널로 **추가**되고, 기존 두 답변이 남는다

## D. 제안이 뜨지 않아야 하는 경우 (선택)

- [ ] **D-1** 위 표의 번역 질문 — 카드 없음 (유료 1 turn)
- [ ] **D-2** 같은 대화에서 `지금 답변으로 충분해요`를 누른 뒤, **같은 주제를 다시
      물어도** 카드가 다시 뜨지 않는다
- [ ] **D-3** 딥 리서치가 이미 선택된 대화에서는 카드가 뜨지 않는다

## E. 게스트·Free (선택)

- [ ] **E-1** 로그아웃 상태에서 같은 질문 — 카드가 **아예 없다**
- [ ] **E-2** Free 계정에서 같은 질문 — 카드가 **아예 없다**

딥 리서치는 Pro 전용이므로, 쓸 수 없는 사람에게는 제안 자체를 하지 않습니다.
이미지 워크스페이스의 "잠금 상태로 노출" 규칙과 **다릅니다** — 그쪽은 구매로
이어지는 기능이고, 이쪽은 이미 끝난 답변 아래의 부가 제안입니다.

## F. 접근성·문구 (선택)

- [ ] **F-1** 카드가 `alert`가 아니며 포커스를 빼앗지 않는다. 두 버튼 각각이
      읽히는 이름을 갖고, 실행 중에는 비활성 상태가 보조기술에 전달된다.
      문구에 `모델 전환`·`다시 답변` 같은 내부 용어가 없다

## 무엇이 실패인가

**B-2가 `fail`이면 이 회차는 실패이고 릴리스 차단입니다.** 고른 것과 다른 모델이
빠졌다면 사용자가 잃은 답변을 되돌릴 방법이 없습니다.

B-1·B-3·A-3이 `fail`이면 **조건부**입니다 — 결함이지만 되돌릴 수 있고, 고쳐서
배포하면 끝납니다.

C·D·E·F의 실패는 이 회차를 실패로 만들지 않습니다. 후속 티켓으로 적습니다.
