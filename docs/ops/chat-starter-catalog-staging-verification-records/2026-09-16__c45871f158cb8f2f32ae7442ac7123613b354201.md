**F-3 참고 (관측의 범위):**

- 캡처는 **한 행**입니다. A 구획의 전환 가운데 flag를 켠 행으로 보이며, 끈 전환의
  행은 캡처에 없습니다.
- metadata는 **저장 후 값의 스냅샷**이고 이전 값이 없습니다. 이 행만으로는 이번
  저장에서 어느 키가 바뀌었는지 알 수 없습니다.
- 키 이름이 `feature.chatStarterEnabled`가 아니라 `chatStarterEnabled`입니다.
- metadata에 `voiceInputEnabled` 키가 없습니다. 이 flag는 이 저장 경로의 요청
  본문에 없고(`app/api/admin/app-settings/route.ts`), 의도적으로 writer가 없습니다
  (`tests/appSettingWriters.test.mjs`).
- 캡처의 REQUEST 칸에 IP와 User-Agent가 있지만 이 기록에는 옮기지 않았습니다.
