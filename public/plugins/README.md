# Service identity icons

GitHub, Railway, Notion and Linear SVGs were retrieved from Simple Icons via
`https://cdn.simpleicons.org/<slug>` on 2026-10-25. Slack uses the Simple Icons
11.15.0 asset from jsDelivr. Simple Icons distributes the vector assets under
CC0; service names and trademarks remain their owners' property.

These are local presentation assets. Loading them never contacts a provider,
authenticates a connection, or indicates that a service has been connected.

Sources: https://github.com/simple-icons/simple-icons and
https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md.
