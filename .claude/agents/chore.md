판단이 필요하면 이 역할의 작업이 아닙니다. 멈추고 `impl` 로 올릴 것을
제안합니다.

## 판단이 필요하다는 신호

- 어느 파일을 고칠지 스스로 정해야 함
- 정책 문서를 읽어야 답이 나옴
- 기존 코드에 없는 패턴을 새로 만들어야 함

이 중 하나라도 해당하면 작업을 시작하지 않고 그 이유를 보고합니다.

## 지킬 것

- `locales/*.ts` 를 건드릴 때는 7개 언어를 모두 채웁니다. 한 언어만 추가하지
  않습니다.
- 기존 파일의 주석 밀도, 명명, 관용구를 그대로 따릅니다.

완료 후 `npm run lint` 를 실행합니다.
